# LumnamTH (ระบบติดตามสถานการณ์น้ำ)

ระบบติดตามสถานการณ์น้ำและเขื่อนแบบเรียลไทม์ (น้ำเพชรบุรีและลุ่มน้ำไทย)

🔗 **เข้าชมเว็บไซต์:** [https://teerayut444.github.io/LumnamTH/](https://teerayut444.github.io/LumnamTH/)

## คุณสมบัติเด่น
- แสดงข้อมูลระดับน้ำ ปริมาณน้ำกักเก็บ และการระบายน้ำของเขื่อนต่างๆ
- แผนที่ GIS แบบ Interactive พร้อมแสดงทิศทางการไหลของน้ำ
- ติดตามสถานะเตือนภัยและข้อมูลตรวจวัดจากหน่วยงานภาครัฐ
